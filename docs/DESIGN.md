# 크누피 디자인 기획 — Relationship-Centric Redesign

> 경북대학교 실시간 퀴즈 플랫폼 **크누피**의 관계 중심(Relationship-Centric) 디자인 기획.
> 상태: **기획(Plan) — 코드 미적용.** / 작성: 2026-06 / 적용 범위: `frontend`

---

## 0. 브랜드
- **서비스명: 크누피** (KNU + Quiz, 한국어 표기). 친근한 어감 → **마스코트 이름으로도 사용**(§10).
- 한 줄 정체성: **경북대(KNU)의 정체성 + 퀴즈 게임의 생동감.**
- 톤: 진지하지만 차갑지 않게, 즐겁지만 가볍지 않게.

## 1. 진단 — 왜 딱딱한가
현재 디자인은 `globals.css`/`design.ts` 기준 **Airbnb 토큰을 그대로 복제**한 거래형/중립 미학이다. *차분함이 미덕인 마켓플레이스* 규칙을 *흥분이 미덕인 퀴즈 게임*에 적용해서 미스매치가 난다.

| 현재 토큰 | 주는 느낌 | 퀴즈에 필요한 것 |
|---|---|---|
| Rausch(#ff385c) 단색 + 회색 위계만 | 중립·정적 | **공식 브랜드색(KNU RED)** + 에너지 + 팀 색 |
| 단일 그림자 tier, hairline 테두리 | 평면·사무적 | 다단계 깊이, 무대감 |
| `transition: color 150ms`뿐 (모션 X) | 죽어있음 | 타이머·점수·환호 모션 |
| 라이트 전용 흰 배경 | 문서 같음 | 라이브는 **다크 무대** |
| 마이크로카피·캐릭터 없음 | 기계적 | 따뜻한 말투·마스코트 |

또한 **화면 중심**(로그인→작업→끝) 구조라 호스트의 히스토리·참가자의 정체성 등 *관계*가 축적되지 않는다.

## 2. 경북대(KNU) 브랜드 컬러
### 공식 전용색 (UI 시스템)
| 색 | CMYK | PANTONE | 환산 RGB / HEX(대표) |
|---|---|---|---|
| **KNU RED** | C10 M100 Y100 K0 | DS87-1C | RGB(230, 0, 0) ≈ `#E60000` |
| **KNU GRAY** | C5 M5 Y7 K50 | DS325-1C | RGB(121, 121, 119) ≈ `#797977` |

> HEX는 CMYK 환산 대표값. 인쇄/정밀 매칭 시 **PANTONE DS87-1C / DS325-1C**가 기준.
> (참고: 1952년 지정 *전통 교색*은 **자주(위엄·권위·정의)+금(신라 금관의 고귀함)** — 시상/세리머니의 **골드 포인트**로 헤리티지 계승 가능.)

### 디자인 매핑 (퀴즈 맥락에 부합)
| KNU 색 | 역할 | 이유 |
|---|---|---|
| **KNU RED `#E60000`** | **브랜드 프라이머리** — CTA·호스트 헤더/조종석·정답 셀러브레이션·강조 | 강렬한 레드 = 퀴즈 게임의 에너지 + 경북대다움 |
| **KNU GRAY `#797977`** | **구조/중립** — 본문 보조·테두리·아이콘·다크 무대 베이스(딥 그레이) | 레드를 받쳐주는 차분한 뼈대 |
| 골드(헤리티지) `#C9A227` | **승리/성취 액센트**(선택) — 1등 시상대·뱃지 | 전통 교색 "금"의 고귀함 → 우승 보상 |
| 기존 Rausch 핑크 | 브랜드 지위 해제(폐기) | "생성형 Airbnb 핑크"가 딱딱+밋밋의 근본 원인 |

### 팔레트 운영 (대표값 — 정밀값은 PANTONE 기준)
```
브랜드      KNU RED   #E60000  (press #C00000 / disabled #F4B3B3 / 라이트틴트 #FFF2F2)
중립        KNU GRAY  #797977  (텍스트 #2A2A2A / 보조 #6A6A6A / hairline #E3E3E3)
다크 무대    Stage Ink #17161A  (그레이 기반 딥 차콜) + RED 네온 글로우
승리(선택)   Gold      #C9A227
정답        Correct   #1FA971 (그린) + 골드 글로우  ← 브랜드 레드와 충돌 피해 그린 사용
오답        Wrong     중립 그레이 dim + 흔들림 + ✕  ← 두 번째 레드를 쓰지 않음(브랜드 레드 보호)
4지선다      파 #2D7FF9 · 노 #F4B400 · 초 #1FA971 · 보라 #7C4DFF  (레드는 브랜드 전용이라 제외)
```
- **접근성**: 정답/오답·팀·선택지를 **색만으로 구분하지 않는다**(도형 △○□◇ + 아이콘 + 모션 병행). 대비 WCAG AA, `prefers-reduced-motion` 대응.

## 3. 두 개의 관계 (Pillar 3 — Relationship Architecture)
하나의 시각언어, **두 개의 인격**.

| | 호스트(교수/강사) | 참가자(학생) |
|---|---|---|
| 관계 길이 | **장기·반복**(학기 단위) | 짧지만 **감정적으로 강렬**, 같은 강의면 반복 |
| 핵심 욕구 | 빠른 제작·AI 위임·인사이트 | 재미·긴장·소속감·인정 |
| 디자인 인격 | **신뢰 가는 조종석(KNU Red/Gray chrome)** | **축제/아케이드(다크 무대 + RED 네온)** |
| 관계 초점 | 메모리·AI 신뢰·목표 연속성 | 가벼운 정체성·감정 피드백 |

## 4. 5 Pillars 적용
**Pillar 1 — Memory(정적 설정 → 진화하는 기억)**
- 호스트: **"내 퀴즈 서재"가 시간에 따라 성장**(최근·자주 쓴·정답률 낮은 퀴즈) + **세션 히스토리 타임라인**.
- 참가자: **가벼운 정체성**(닉네임+아바타+색) 기억, 같은 강의 반복 참여 시 **스트릭·뱃지**.

**Pillar 2 — Trust(AI 퀴즈 생성의 3단계 신뢰)**
- ① **투명**: 문제마다 *출처 문장 하이라이트 + 난이도/신뢰도* → ② **선택적**: 의심스러운 것만 검토 → ③ **자율**: 초안 자동 생성·일괄 검수. **수정 = AI 학습 신호**. (Gemini 생성 기능에 직접 적용)

**Pillar 3 — 관계 아키텍처**
- 호스트 홈을 *퀴즈 목록*이 아니라 **"관계 대시보드"**로: 이번 강의 회차·진행·다음 추천 액션.

**Pillar 4 — 스스로 경로를 짜는 시스템(Proactive)**
- 넛지: *"지난 세션 3번 문제 정답률 28% — 복습 퀴즈 만들까요?"* · *"매주 수요일 퀴즈 — 다음 세트 초안 미리?"*
- **협업 캔버스**: AI와 함께 퀴즈 세트 공동 구성.

**Pillar 5 — 새 성공 지표** → §9.

## 5. "Warm Arcade" 디자인 언어 (딱딱함 해소)
- **컬러**: §2의 **KNU Red(브랜드) + KNU Gray(구조)** 중심 + 라이브는 다크 무대 + RED 네온, 승리는 골드 액센트.
- **타이포**: Inter 유지, 단 **점수·타이머·PIN은 디스플레이급 큰 숫자**로 주인공화(위계·대비 강화).
- **깊이 & 모션**: 단일 그림자 → **다단계 elevation** + **의미 있는 모션**(§7). 모션 = 게임의 피드백 언어.
- **개성**: 마스코트 크누피(§10), 상황별 마이크로카피("거의 다 왔어요!", "아쉬워요 😅"), 선택형 사운드/햅틱.

## 6. 화면별 리디자인 방향 (현재 → 제안)
- **PIN 입장**: 작은 폼 → **대형 코드 입력 = 게임 입장**(큰 숫자·엔터 임팩트).
- **참가자 대기실**: 빈 화면 → **"무대 입장 전 라운지"**(아바타 모임·라이브 카운트).
- **문제 화면**: 흰 문서 → **다크 무대 + 대형 타이머 링**, 4지선다 = **색+도형**(접근성), 제출 즉시 햅틱·피드백.
- **개인 결과**: 단순 정/오 → **정답 셀러브레이션 / 오답 위로(크누피)** + **순위 변동 모션** + **AI 해설**(따뜻하게).
- **리더보드**: 정적 표 → **순위 이동 애니메이션 + 골드 1등 시상대 + 팀 색**.
- **호스트 대시보드**: 목록 → **관계 홈**(서재 성장 + 추천 + 인사이트 카드).
- **호스트 라이브 콘솔**: **"방송 PD 조종석"**(현재 문제·실시간 정답률·리더보드·다음 버튼) 시네마틱(KNU Red/Gray chrome).
- **AI 생성**: §4 Pillar 2의 **신뢰 3단계 UI + 협업 캔버스**.

## 7. 핵심 게임 모션 3종 (가성비 최고 — 적은 코드, 큰 체감)
1. **타이머 카운트다운 링** (긴장)
2. **점수 카운트업 + 순위 변동** (보상)
3. **정답 셀러브레이션**(RED+골드 컨페티) / **오답 흔들림 + 크누피 위로**

## 8. 로드맵
- **Phase 1 — 감각적 빠른 승리**: 토큰 확장(KNU Red·Gray·다크 무대·elevation·모션) + 게임 모션 3종. *코드 적고 체감 큼 → 여기부터.*
- **Phase 2 — 관계 표면**: 호스트 관계 홈 + 퀴즈 서재 메모리, 참가자 정체성/스트릭.
- **Phase 3 — AI 신뢰**: AI 생성 3단계 + 인사이트 넛지.
- **Phase 4 — 측정**: 관계 지표 계측.

## 9. 성공 지표 (관계 중심)
- **관계품질**: 호스트 재사용률, AI 위임도, 시스템 재신뢰 빈도.
- **복리가치**: 제작 시간 月1 vs 月6(↓), 누적 인사이트 활용.
- **참가자**: 재참여율, 감정 반응(환호/셀러브레이션 트리거), 완주율.
- **AI 신뢰**: AI 초안 수정률(↓ = 신뢰 상승).
> 세션 체류시간/클릭 같은 전통 지표가 아니라 **관계가 좋아지는지**를 본다.

## 10. 마스코트 "크누피"
- **이름 = 서비스명**과 동일(친근함·기억성).
- 모티브 후보: 경북대 상징 — **별/첨성대**("첨성인", 퀴즈에서 별=정답 은유) · **호반우**(호랑무늬소, 성실·봉사) · **감꽃**(교화).
- 역할: **상황별 표정**(긴장/환호/위로)으로 로딩·빈 화면·결과·오답 위로에서 활약 → 딱딱함을 가장 직접적으로 해소.
- 컬러: **KNU Red 바디 + Gray 디테일 + 골드 포인트**.
